# Portfólio — Pedro Henrique Prates

Portfólio pessoal de **Pedro Henrique Prates**, designer e desenvolvedor.

Site estático feito com **HTML, CSS e JavaScript** puro — sem frameworks.

## Seções
- **Projetos & SaaS** — Quiz de Carreira em Dados e Phivo (plataforma de carrosséis virais)
- **Resultados no Instagram** — posts com mais de 1 milhão de visualizações somadas
- **Sobre**, **Skills** e **Contato**

## Rodar localmente
Basta abrir o arquivo `index.html` no navegador.

## Estrutura
```
index.html    # conteúdo e estrutura
styles.css    # estilos
script.js     # animações e interações
assets/       # imagens (prints dos posts e telas dos SaaS)
```
